# Okto 2.0 — планер и помощник для работы

Дата: 2026-10-05 · Статус: утверждено

## Цель

Превратить Okto (счётчик + Pomodoro) в личный планер: задачи, календарь в стиле Apple Calendar и главная со статистикой. Дизайн-код — тот же, что в Okto 1.0. Всё полностью бесплатно. Пользователь — один человек, работает с компьютера (сайт) и с Android (позже — APK с виджетом).

## Решения

| Вопрос | Решение |
|---|---|
| Аудитория | Личный инструмент |
| Синхронизация | С самого начала, через Firebase (план Spark, бесплатно). Без входа — локальный режим |
| Телефон | Android. Позже: Capacitor → APK + виджет на Kotlin (отдельный подпроект) |
| Стек | Vite + Svelte 5 + TypeScript, Firebase Auth (Google) + Firestore с офлайн-кэшем, GitHub Pages |
| Разделы | Главная · Задачи · Календарь · Фокус |
| Задачи v1 | подзадачи, повторы, напоминания, учёт фокус-времени. Без Inbox и быстрого ввода |
| Напоминания | На сайте — пока вкладка открыта. В APK — локальные уведомления (позже) |

Не входит в эту версию: быстрый ввод с распознаванием, Inbox, командная работа, push при закрытом сайте, APK и виджет.

## 1. Каркас и навигация

- Телефон: нижняя панель из 4 иконок с подписями (обводка 1.8px, активная `--ink`, неактивные `--muted`). Плавающая кнопка «+» в стиле `.circle.big` — новая задача; на «Фокусе» скрыта.
- Компьютер (≥ 900px): левая колонка — логотип `okto`, разделы, кнопка «Новая задача», настройки и язык. Контент — остальная ширина; календарь — на всю.
- Шапка на телефоне: логотип, язык, настройки — как в 1.0. В настройках добавляется блок «Аккаунт» (вход через Google, статус синхронизации).
- Маршрутизация через hash (`#/`, `#/tasks`, `#/calendar`, `#/focus`) — работает на GitHub Pages без серверных правил.

Структура кода:

```
src/
  lib/model.ts        типы и нормализация данных
  lib/date.ts         работа с датами (локальные 'YYYY-MM-DD')
  lib/recurrence.ts   повторы (чистые функции)
  lib/stats.ts        показатели главной (чистые функции)
  lib/layout.ts       раскладка пересекающихся блоков календаря
  lib/migrate.ts      перенос данных Okto 1.x
  lib/merge.ts        слияние локальных и облачных записей
  lib/store.svelte.ts единое состояние приложения + сохранение
  lib/sync.ts         Firebase (единственное место, где он импортируется)
  lib/i18n.ts         RU/EN
  lib/alerts.ts       звук, вибрация, уведомления
  screens/            Home, Tasks, Calendar, Focus
  components/         общие элементы
  styles/             токены и темы из 1.0
```

## 2. Модель данных

Все записи — в `users/{uid}/{collection}/{id}` Firestore; локально — в `localStorage` под ключом `okto-v3`.

```ts
Task {
  id, title, note,
  listId: string,
  priority: 0|1|2|3,
  date: string|null,          // 'YYYY-MM-DD', null → «Без даты»
  start: string|null,         // 'HH:MM', null → весь день
  duration: number,           // минуты, по умолчанию 30
  subtasks: {id,title,done}[],
  repeat: null | { freq: 'day'|'weekday'|'week'|'month', interval: number, until: string|null },
  reminder: number|null,      // минут до начала
  done: boolean,              // для обычных
  doneAt: number|null,        // когда выполнена (для статистики)
  doneDates: string[],        // для повторяющихся
  skipDates: string[],        // исключённые дни серии
  focusMinutes: number,
  createdAt, updatedAt: number, deleted: boolean
}
List    { id, name, color, order, updatedAt, deleted }
Session { id, start: number, minutes, taskId|null, updatedAt, deleted }
Counter { id, name, target, step, count, color, history, daily: {date: number}, order, updatedAt, deleted }
Settings{ lang, theme, notify, sound, vibrate, pomo{...}, dashboard: Block[], hiddenLists, updatedAt }
Block   { type: 'tasks'|'focus'|'streak'|'next'|'counter', counterId? }
```

Устройство-локальное (не синхронизируется): режим «Фокуса», активный тег, состояние таймера Pomodoro, секундомер, блокировка, привязанная к фокусу задача.

Повторы: одна запись с правилом; вхождения вычисляются для диапазона. «Изменить только эту» — новая задача-копия + дата в `skipDates`. «Все будущие» — серия обрезается `until = день−1`, создаётся новая серия.

Конфликты: побеждает больший `updatedAt` на уровне записи. Удаление мягкое (`deleted: true`).

Списки по умолчанию: «Личное» (синий), «Работа» (фиолетовый).

## 3. Экран «Задачи»

- Заголовок Inter Display «Задачи», под ним «Сегодня 3 из 7».
- Капсулы-фильтры: Сегодня · Предстоящие · Все · Без даты · Выполненные, затем списки с цветной точкой и «+ Список». Повторный тап по активному списку — редактирование (как теги в 1.0).
- Строка задачи: круг-чекбокс (обводка 2px, цвет по приоритету: нет `--ink`/синий/оранжевый/красный), название, справа время; вторая строка — список · подзадачи · 🍅 минуты · ↻ · 🔔 (пустое скрыто).
- «Сегодня» включает просроченные (красная группа сверху). «Предстоящие» — группы по дням на 14 дней вперёд.
- Выполнение → тост «Выполнено · Отменить». Свайп влево (телефон) — «Завтра» / «Удалить».
- Шторка редактора: название, заметка, капсулы дата / время+длительность / повтор / напоминание / список / приоритет, подзадачи, кнопки «Удалить» · «Сохранить» и ▶ «Фокус на задаче».
- По умолчанию дата — сегодня, без времени. Из календаря — подставляются день и час.
- Пустое состояние: «НА СЕГОДНЯ ВСЁ» + подсказка.

## 4. Календарь (стиль Apple Calendar)

- Шапка: «Октябрь 2026» (месяц `--ink`, год `--muted`), «Сегодня», ‹ ›; сегмент День · Неделя · Месяц.
- Сегодня — залитый круг `--accent`. Красная линия текущего времени с кружком.
- Блок задачи: фон `color-mix(списка 15%)`, полоска 3px слева, название и время; выполненные — полупрозрачные, зачёркнутые. Без времени — строка «весь день».
- Телефон: Месяц — сетка с точками + список дня; День — шкала часов + лента дней недели; Неделя — 3 дня.
- Компьютер: Неделя по умолчанию (7 колонок), слева мини-календарь и списки с флажками видимости; Месяц — ячейки со строками задач и «ещё N».
- Клик по пустому месту — новая задача с днём и часом. Перетаскивание — перенос, нижний край — длительность, шаг 15 мин; на телефоне — после долгого нажатия. Для повторяющихся — вопрос «Только эту / Все будущие».

## 5. Главная

- Приветствие по времени суток (Inter Display), дата серым, справа «Изменить».
- Блоки без карточек, разделены линиями `--line`; телефон — 1 колонка, компьютер — сетка 2–3 колонки.
- Блоки: Задачи (3 / 7 + линия прогресса), Фокус (1 ч 40 м · 4 фокуса), Серия (дни подряд с задачей или фокусом; сегодняшний пустой день не обнуляет), Дальше (ближайшая задача со временем), Тег счётчика (48 / 75 + линия).
- По умолчанию: Задачи, Фокус, Серия, Дальше.
- Тап по блоку: шторка со столбиками за 7 дней и итогом за 30 дней; «Задачи» → экран задач, «Дальше» → календарь, тег → «Фокус» с тегом.
- «Изменить»: покачивание, «−» скрыть, ⋮⋮ перетаскивание, «+ Добавить блок», «Готово».

## 6. Фокус, языки, синхронизация, ошибки, тесты

- «Фокус» — экран Okto 1.0 без изменений поведения. Плюс капсула привязанной задачи над таймером (с ✕). Каждый завершённый фокус → `Session` (+ `focusMinutes` задаче).
- Счётчик пишет итог дня в `daily`.
- Миграция `okto-v2` / `okto-counter-v1` → `okto-v3` при первом запуске; старые ключи не удаляются.
- Без ключей Firebase (`VITE_FIREBASE_*`) — локальный режим, кнопка входа скрыта, статус «Не настроено». Ключи публичные (Firebase web config), доступ защищён правилами Firestore `request.auth.uid == userId`.
- Ошибки: офлайн — локально + Firestore-очередь; нет storage — работа в памяти + тост; битые данные — нормализация; уведомления запрещены — тост.
- Напоминания на сайте: проверка раз в 30 с, пока вкладка открыта; каждое срабатывает один раз (ключ задача+дата).
- i18n: все строки RU/EN; даты через `Intl`; неделя с понедельника (RU) / воскресенья (EN).
- Темы: 7 тем 1.0, только токены.
- Тесты Vitest: recurrence, stats, migrate, merge, layout. Ручная проверка в браузере на 375px и 1280px.
