## 📌 О проекте

**Okto** — небольшой веб‑счётчик для повседневных задач: повторений, привычек, предметов или любых других вещей, которые нужно посчитать. Интерфейс открывается по ссылке, подстраивается под телефон и компьютер и не требует регистрации.

Счёт, цель и выбранная тема сохраняются в локальном хранилище браузера. Они не отправляются на сервер и не синхронизируются между устройствами.

| | |
|---|---|
| 🔢 **Счёт в один тап** | Нажмите на число, чтобы увеличить значение выбранным шагом |
| 🎯 **Цель и прогресс** | Задайте цель и следите за полосой прогресса |
| ↩️ **Отмена** | Верните значение до последнего изменения |
| 🌓 **Две темы** | Переключайтесь между светлым и тёмным оформлением |

<br>

## ✨ Возможности

### Счётчик
- Нажатие по большой цифре прибавляет выбранный шаг.
- Быстрые шаги: **+1**, **+5** и **+10**.
- Клавиши `Пробел` и `Enter` увеличивают счёт, если фокус не находится в поле или на кнопке.
- Кнопка отмены восстанавливает предыдущее значение.
- Сброс счёта просит подтверждение.

### Цель и оформление
- Настраиваемая цель от 1 до 999 999.
- Полоса показывает прогресс и останавливается на 100%.
- Okto сообщает, когда цель достигнута.
- Светлая и тёмная темы запоминаются в браузере.
- Число автоматически уменьшается, если для него становится мало места.

### Поделиться
- Отправьте текущий результат через системное меню браузера.
- Если меню недоступно, Okto предложит скопировать текст счёта.

## 🧠 Как это устроено

Okto работает как статическое веб‑приложение — без сервера, аккаунта и сторонних библиотек. HTML задаёт интерфейс, CSS отвечает за оформление и адаптивность, а JavaScript обновляет счёт, цель и тему.

```text
Браузер
  ├── index.html     интерфейс счётчика
  ├── style.css      светлая/тёмная темы и адаптивная сетка
  ├── app.js         счёт, шаг, отмена и сохранение
  └── localStorage   счёт, цель, шаг, история и тема
```

GitHub Actions автоматически публикует сайт в GitHub Pages при изменениях в ветке `main`.

## 🚀 Быстрый старт

**В браузере:** [откройте веб‑версию Okto](https://sailxx.github.io/Okto/). Устанавливать приложение не нужно.

**Локально:** скачайте репозиторий и откройте `index.html` в современном браузере. Сборка и установка пакетов не требуются.

## 🔒 Данные и приватность

- Счёт, цель, шаг и тема хранятся только в локальном хранилище браузера.
- Регистрация и серверная база данных не используются.
- Очистка данных сайта в браузере удалит сохранённый счёт.
