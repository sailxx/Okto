# Okto

Минималистичный счётчик для телефона и компьютера. Нажимайте на большую область, чтобы увеличить число. Интерфейс доступен в светлой и тёмной темах.

## Возможности

- Счётчик с увеличением и шагом назад
- Сброс с подтверждением
- Светлая и тёмная темы
- Настраиваемая цель и индикатор прогресса
- Сохранение значения и оформления в браузере
- Адаптивный интерфейс и доступные подписи для кнопок
- Поделиться счётом через системное меню, если браузер это поддерживает

## Запуск

Откройте `index.html` в браузере. Для публикации можно загрузить содержимое этой папки в GitHub Pages.
